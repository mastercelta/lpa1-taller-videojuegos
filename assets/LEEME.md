# Assets

Si un PNG con estos nombres existe, el juego lo usa en vez del dibujo por código. Todos se escalan a 48×48.

| Archivo | Qué es |
|:---|:---|
| `piso_0.png` … `piso_3.png` | Variantes de la baldosa del piso |
| `zona_venta.png` | Baldosa de la tienda |
| `obstaculo.png` | Bloque de código comentado |
| `sprites/estudiante_abajo.png`, `_arriba`, `_izquierda`, `_derecha` | El protagonista mirando a cada lado |
| `sprites/EnemigoNullPointer.png` | NullPointer |
| `sprites/EnemigoBucleInfinito.png` | Bucle Infinito |
| `sprites/EnemigoVariableGlobal.png` | Variable Global |
| `sprites/EnemigoMemoryLeak.png` | Memory Leak |
| `sprites/EnemigoJefe.png` | El jefe final |

Los sprites van con fondo transparente.
