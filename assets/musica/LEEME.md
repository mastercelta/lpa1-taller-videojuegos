# Música

Pistas de [15 Melodic RPG Chiptunes](https://opengameart.org/content/15-melodic-rpg-chiptunes) de **Aureolus_Omicron**, licencia CC0.

Descomprime `15_melodic_rpg_chiptunes_ogg.zip` aquí con los nombres originales. El juego usa estas pistas (ver `ui/musica.py`):

| Momento | Archivo |
|:---|:---|
| Título y menú | `rpgchip01_title_screen.ogg` |
| Intro | `rpgchip02_bittersweet_story.ogg` |
| Tienda | `rpgchip03_town.ogg` |
| Explorando | `rpgchip08_castle_on_the_mountain.ogg` |
| Aparece el jefe | `rpgchip12_the_evil_one.ogg` |
| Game over | `rpgchip15_game_over.ogg` |

Si no están, en el título suena una melodía original generada por código.
